Perguntas frequentes

Preciso de internet?

Depois do primeiro carregamento, o sistema funciona sem conexão.

Onde ficam os meus dados?

No próprio dispositivo, dentro do navegador. Não há servidor nem mensalidade de hospedagem. Por isso o sistema tem exportação e restauração de backup, e é importante fazer cópias com frequência.

Posso usar no celular e no computador?

Sim. O sistema pode ser instalado como aplicativo nos dois. Os dados de cada dispositivo ficam separados; para levar de um para outro, use o backup.

Como recebo a licença?
